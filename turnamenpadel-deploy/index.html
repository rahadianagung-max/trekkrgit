untuk turnamen profesional

Dari pendaftaran hingga podium — kelola seluruh turnamen padel kamu dalam satu platform terintegrasi.

🖥️
Scoreboard TV Real-time
Tampilkan skor langsung di layar TV LED besar. Auto-update tanpa perlu refresh, layout landscape yang bersih dan mudah dibaca dari jauh.
📱
Live Score di HP
Penonton scan QR code langsung dapat live score di HP masing-masing. Semua pertandingan dalam satu halaman mobile-friendly.
⚙️
Admin Panel Lengkap
Input skor, atur grup, jadwal pertandingan, dan update hasil langsung dari panel admin. Tidak perlu aplikasi khusus — cukup browser.
📊
Sistem ELO Otomatis
Rating pemain dihitung otomatis setiap selesai turnamen menggunakan algoritma ELO. Rekam jejak performa tersimpan permanen.
🏆
Format Grup & Knockout
Dukung format round-robin grup dan babak gugur. Klasemen otomatis berdasarkan poin, set, dan game.
☁️
Cloud-based, Zero Install
Berjalan 100% di browser. Data tersimpan di Google Sheets — mudah di-backup, export, dan audit kapan saja.
Cara Kerja
Siap dalam hitungan menit

Setup turnamen cepat, tidak perlu instalasi, langsung bisa digunakan di hari H.

Buat Event Baru
Buka admin.html, masukkan nama event dan daftar peserta. Sistem langsung generate jadwal pertandingan.
Tampilkan di TV
Buka tv.html di browser TV atau laptop yang terhubung ke proyektor. Scoreboard tampil otomatis real-time.
Penonton Scan QR
QR code muncul di layar TV. Penonton scan dan langsung lihat semua skor live di HP masing-masing.
Input Skor
Admin input hasil setiap pertandingan. Semua layar (TV + HP) update otomatis dalam hitungan detik.
Selesai & Rating Update
Setelah turnamen selesai, rating ELO semua pemain otomatis dihitung dan diperbarui di database global.
Tampilan Layar
Dirancang untuk setiap layar

TV LED, smartphone, hingga tablet — semua tampil optimal dengan tema gelap yang elegan.
